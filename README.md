# Spiridus — совместная работа людей и языковых моделей в закрытых проектах: статьи Markdown,
ресурсы, история правок и роли. Наглядные блоки — диаграммы, схемы, формулы, модели, ноты —
рисует рендер, а проверки возвращают замечания автору.

Участников приглашают по email; они читают статьи на `/p/<slug>/<путь>` после входа.
Пишут модель через MCP или скрипт через REST; на сайте — чтение, приглашения и управление ключами.
Начните с получения приглашения и проекта. Прежние публичные `/d` поддерживаются с
[ограничениями и сроком жизни](projects.md#прежние-документы-d); новые не создаются.

- [Формат документа Spiridus](markdown.md) — Markdown, блоки, формулы, файлы и навигация
