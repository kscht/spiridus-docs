# `tabulator` — интерактивная таблица Tabulator

Таблица на [Tabulator](https://tabulator.info/docs/6.6) 6.6.1 (MIT): сортировка щелчком по шапке,
фильтры в шапке, группы строк, страницы, закреплённые колонки, форматтеры (полоски, звёзды, галочки,
деньги), итоги по колонкам. Внутри блока — **настройки Tabulator как есть**: те же ключи, что в его
документации (`columns`, `data`, `layout`, `groupBy`, `pagination`…). Пишутся JSON (можно с
комментариями и без кавычек у ключей) или кодом `table = {...}` — тогда работают и функции
(`formatter: (cell) => …`). Таблица живёт во фрейме запускателя, как ECharts и Vega.

```tabulator
{
  "data": [
    {"ученик": "Иванова", "класс": "9Б", "балл": 87, "сдано": true},
    {"ученик": "Петров",  "класс": "9Б", "балл": 64, "сдано": true},
    {"ученик": "Сидоров", "класс": "9А", "балл": 41, "сдано": false}
  ],
  "groupBy": "класс",
  "columns": [
    {"title": "Ученик", "field": "ученик", "headerFilter": "input"},
    {"title": "Балл", "field": "балл", "hozAlign": "right", "sorter": "number",
     "formatter": "progress", "formatterParams": {"min": 0, "max": 100, "color": ["#e57373", "#ffb74d", "#81c784"]},
     "bottomCalc": "avg", "bottomCalcParams": {"precision": 1}},
    {"title": "Сдано", "field": "сдано", "formatter": "tickCross", "hozAlign": "center"}
  ]
}
```

## Данные

- **В настройках** — `"data": [{…}, …]`, строка — объект «поле — значение».
- **Файлом документа** — `"data": "file:оценки.csv"` и в том же документе блок
  ```` ```csv file=оценки.csv ````: первая строка — названия полей, числа (и «3,5») — числами.
  Подходят `.csv`, `.tsv`, `.json`.
- **Без `columns`** колонки строятся сами по полям данных (`autoColumns`).
- Сети во фрейме нет: `ajaxURL` и подобное не работают — предупреждение под таблицей.

## Что полезно знать

- `layout` по умолчанию — `fitDataFill`; в узкой колонке (телефон, уже 560 точек) — `fitColumns` с
  `responsiveLayout: "collapse"`: колонки, что не влезли (по 90 точек и шире), — списком
  «название — значение» под строкой, без прокрутки вбок. Свой `layout` или `responsiveLayout` это
  отменяет. Первая колонка остаётся всегда, остальные уходят справа налево; свой порядок —
  `responsive` у колонки: 0 — не уходит никогда, из остальных раньше уходит та, у которой число меньше.
- Длинная таблица (больше 25 строк, без `height` и
  `pagination`) получает свою прокрутку высотой 480 точек — заголовки остаются на месте.
- Подписи Tabulator — по-русски (`locale: "ru"`): страницы, фильтры, группы.
- Тема — атрибутом забора `theme`: `simple` (по умолчанию), `modern`, `site`, `midnight` (тёмная),
  `default`:

  ````markdown
  ```tabulator theme=modern
  ````

- Итоги считает сама таблица (`bottomCalc`: `sum`, `avg`, `min`, `max`, `count`), а не автор:
  поэтому они сходятся с данными.
- Форматтер `html` и картинки по адресам (`image`) в документе не пригодятся: внешние адреса
  фрейм не грузит, а HTML в данных — тот же код документа, что и функции.
- «⤢» — таблица на весь экран.
- `render_check` проверяет таблицу по снимку той же таблицы; значки форматтеров (`tickCross`,
  `star`) на снимке не видны — у читателя они есть.

Для текстовых таблиц с объединёнными ячейками — блок `table`.
