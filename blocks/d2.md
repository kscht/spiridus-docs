# `d2` — схемы D2

Схема на языке [D2](https://d2lang.com/): архитектура, потоки данных, таблицы баз данных,
классы, последовательности, сетки. Связи — `->`, `<-`, `<->`, `--`; вложенность — фигурными
скобками; подписи на Markdown — `|md … |`.

```d2
Ученик -> Комната: вопрос
Комната: {
  Модель
  Документ
  Модель -> Документ: правка
}
Комната.Документ -> Ученик
```

Раскладка и тема — в самой схеме:

```d2
vars: {
  d2-config: {
    layout-engine: elk
    theme-id: 4
    sketch: true
  }
}
a -> b -> c
a -> c
```

Схема рисуется вживую во фрейме-песочнице запускателя (volkodlak.ru); на странице проверки
— картинкой. Импорты (`@файл`) и ссылки (`link:`) не работают: у блока нет ни сети, ни файлов.

Иконки — только из наших наборов, `icon: набор:имя` (список — `render_icons`): `affinity` —
сетевые цветные (`router`, `switch`, `firewall`, `server`, `cloud`, `office`; `-green`, `-red`,
`-gray`, `-line`), `affinity-circle` — те же в круге, `mdi` — значки устройств и ИТ, `logos` —
логотипы продуктов. С `shape: image` узел — сама иконка, подпись под ней; у других фигур иконка в
углу. Иконка по адресу в интернете — ошибка с объяснением.

```d2
direction: right
inet: Интернет { shape: image; icon: affinity:globe }
fw: Экран { shape: image; icon: affinity:firewall }
sw: Коммутатор { shape: image; icon: affinity:switch }
srv: Сервер 198.51.100.10 { shape: image; icon: affinity:server }
inet -> fw -> sw -> srv
```

Раскладки — `dagre` (по умолчанию) и `elk`; `tala` недоступна. Не больше 32 КБ.

Ширина: `direction: right` с пятью и больше узлами в ряд выходит шире колонки (до 2000 точек) —
для документа лучше `direction: down` (по умолчанию) и вложенные контейнеры столбцом.

## Как чинить замечания `render_check`

`render_check` смотрит внутрь рисунка: `label-crossed` — линия через подпись, `label-tight` — линия касается подписи, `label-overlap` — подписи налезают, `label-outside` — подпись шире своей фигуры, `label-small` — после ужатия под колонку мельче 9 точек. В замечании — текст подписи, а в ответе — вырез места (`label-<строка>-<n>.png`).

- `label-crossed` у подписи узла-иконки (`shape: image`) — подпись стоит под значком, связи уходят вниз сквозь неё: `label.near: outside-right-center` (удобно классом: `classes: { dev: { shape: image; label.near: outside-right-center } }` и `class: dev` у узлов); раскладка — dagre (по умолчанию): `elk` считает подпись частью узла, и связи выходят из-под подписи, мимо значка.
- `label-crossed` у подписи узла — линия идёт сквозь контейнер мимо: `direction: down` вместо `right`, развести узлы по вложенным контейнерам, `near` для подписей контейнеров.
- `label-crossed` у подписи связи — короче подпись, или раскладка `elk` (`vars: { d2-config: { layout-engine: elk } }`) — она обходит подписи лучше dagre.
- `label-crossed` или `label-tight` у подписи связи, которая входит в контейнер (подпись легла на его рамку) — подпись к началу связи, у источника: `LLM -> VM.Шлюз: {source-arrowhead.label: инструменты}`.
- `label-tight` — больше промежутки: подписи в две строки (`\n`), иконки с `shape: image` подпись ставят под собой.
