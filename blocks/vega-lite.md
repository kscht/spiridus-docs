# `vega-lite` — диаграммы Vega-Lite

Грамматика графиков [Vega-Lite](https://vega.github.io/vega-lite/) 6: данные, метка (`mark`) и
кодирование полей каналами (`x`, `y`, `color`, `size`, `column`…). Хорош для статистики: агрегаты,
разбиение на графики по категориям (фасеты), слои, гистограммы, регрессия, связанные графики.
Спецификация — JSON (можно JSON5: комментарии, ключи без кавычек).

```vega-lite
{
  "$schema": "https://vega.github.io/schema/vega-lite/v6.json",
  "title": "Средний балл по четвертям",
  "data": {"values": [
    {"четверть": "I", "балл": 4.1}, {"четверть": "II", "балл": 4.3},
    {"четверть": "III", "балл": 3.9}, {"четверть": "IV", "балл": 4.4}
  ]},
  "mark": "bar",
  "encoding": {
    "x": {"field": "четверть", "type": "ordinal", "title": "Четверть"},
    "y": {"field": "балл", "type": "quantitative", "title": "Балл", "scale": {"domain": [0, 5]}}
  }
}
```

## Данные

- **В спецификации** — `"data": {"values": [ … ]}`: для небольших таблиц.
- **Файлом документа** — отдельный блок с именем файла в строке забора, а в спецификации
  `"url": "file:<имя>"`. Читатель видит его свёрнутым («Данные: …») с таблицей. Формат — по
  расширению: `.csv`, `.tsv`, `.json`; для другого — `"format": {"type": "csv"}`.

````markdown
```csv file=рост.csv
класс,пол,рост
5,девочки,146
5,мальчики,145
…
```

```vega-lite
{
  "data": {"url": "file:рост.csv"},
  "mark": "line",
  "encoding": {
    "x": {"field": "класс", "type": "ordinal"},
    "y": {"field": "рост", "type": "quantitative", "scale": {"zero": false}},
    "color": {"field": "пол", "type": "nominal"}
  }
}
```
````

Адреса в интернете (`"url": "https://…"`, наборы `vega-datasets` по ссылке) не загружаются: у
блока нет сети, данные должны быть в документе. Ошибка скажет, какого файла не хватает.

## Что учесть

- Типы полей обязательны: `quantitative` (числа), `ordinal` (порядок: классы, четверти),
  `nominal` (категории), `temporal` (даты: `"2024-09-01"`). Даты и числа подписываются
  по-русски: десятичная запятая, месяцы — «янв», «сентябрь».
- Размер: `"width"` и `"height"` в точках; по умолчанию ~300×300. Колонка документа — 760 точек,
  на телефоне рисунок ужимается: шире 760 не делать. Фасеты (`column`) — не больше 3–4 в ряд.
- Подписи осей и легенды — `"title"` у канала; длинные подписи оси X —
  `"axis": {"labelAngle": -45}` или горизонтальные столбцы (поле категорий на `y`).
- Спецификация Vega (с `marks`, `scales`, `signals`) — блок `vega`, не этот.
- Живой прямо в документе и на весь экран (кнопка «⤢»): подсказки при наведении (`"tooltip": true` у
  `mark` или канал `tooltip`), выбор (`params` с `select`), ползунки (`bind`).
- Не больше 128 КБ спецификации, данных из файлов — до 2 МБ на блок.

## Как чинить замечания `render_check`

- `label-overlap` у подписей оси — `"axis": {"labelAngle": -45}`, `"labelOverlap": true` (прорежает подписи) или поле категорий на `y` вместо `x`.
- `label-crossed` — текст поверх меток (`mark: text` слоем): `"dy"`, `"dx"`, `"align"` у текстовой метки, или подписи вне столбцов: `"baseline": "bottom"` и `"dy": -3`.
- `too-wide` — меньше `"width"`, фасеты по строкам (`"row"`) вместо столбцов, или `"columns": 2` у `facet`.
