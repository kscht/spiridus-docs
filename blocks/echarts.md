# `echarts` — диаграммы Apache ECharts

Настройки диаграммы — JSON или запись из галереи ECharts (`option = { … };`, ключи без кавычек,
строки в одинарных кавычках, данные в объявлениях `const data = […]`). Доступны все типы:
столбцы, линии, круговые, точечные, свечи, тепловые карты, календарь, графы, деревья, солнечные,
Санки, параллельные координаты, полярные, карты.

Размер — полями `width` и `height` (по умолчанию 520×300, не больше 1600×1200).

```echarts
{"width":520,"height":300,"xAxis":{"type":"category","data":["янв","фев","мар"]},
 "yAxis":{},"series":[{"type":"bar","data":[53,44,39]}]}
```

**Контуры и карты.** `"type":"map"` (или `geo`) с `"map":"<имя>"` рисует контур из пакета данных
`shapes`: части контура названы, данные красят их по имени — `{"name":"аорта","value":1}`.
Список контуров, их части, авторы и лицензии — в `data/shapes/manifest.json`; автор и лицензия
выводятся под диаграммой сами. Незнакомое имя — ошибка с похожими именами и полным списком.

Настройки-данные (JSON, `option = {…}` без кода) рисуются на странице: в документе —
картинка; наведение мыши или касание делает график живым (подсказки, легенда, масштаб), кнопка
«⤢» — на весь экран. Настройки с кодом — функции (`formatter: function…`, `=>`, `renderItem`) и
вычисления (`.map(…)`, `Array.from`) — рисуются живым графиком во фрейме-песочнице запускателя:
код там и выполняется, у него нет ни сети, ни страницы. Контуры `shapes` (`"map"`) там
недоступны — их держите в настройках без кода. Внешние ссылки (картинки, фон) отклоняются.

Подписи с форматом без кода — по имени: `"formatter": "plain"` — число как есть (годы:
`1812`, а не `1,812`), `"percent"` — «12 %», `"ru"` — «1 234,5». Годы на оси значений —
`"axisLabel": {"formatter": "plain"}`.

Ловушки:
- Подписи категорий в две строки (`\n`) — с `"axisLabel": {"lineHeight": 15}`, иначе строки
  налезают.
- Линия на карте через 180-й меридиан (`lines` с `[-160, 10] → [145, 13]`) идёт через весь мир:
  разбейте её на две — до `[-180, …]` и от `[180, …]`.
- Контур, нарисованный художником (клетка, лист, глаз), раскраске частей (`visualMap`, цвета
  данных) не поддаётся — остаются цвета рисунка; подписи к нему — своими `markPoint`/текстом.
- Карта и точки вместе: `geo` с контуром, ряд `map` с `geoIndex: 0`, ряды `scatter`/`lines` с
  `coordinateSystem: "geo"`.

## Как чинить замечания `render_check`

`render_check` смотрит внутрь рисунка: `label-crossed` — линия через подпись, `label-tight` — линия касается подписи, `label-overlap` — подписи налезают, `label-outside` — подпись шире своей фигуры, `label-small` — после ужатия под колонку мельче 9 точек. В замечании — текст подписи, а в ответе — вырез места (`label-<строка>-<n>.png`).

- `label-crossed` в графе (`type: graph`) — силовая раскладка (`layout: force`) кладёт рёбра через подписи: задайте места узлов (`layout: none`, `x`, `y`) и `label.position: bottom`.
- `label-overlap` у подписей точек и секторов — `labelLayout: { hideOverlap: true }`, у круговой — `avoidLabelOverlap: true`, у осей — `axisLabel.rotate` или `interval`.
- `label-crossed` у подписи на линии графика — `label.position: top` и `distance`.
