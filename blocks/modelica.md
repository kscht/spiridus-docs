# `modelica` — модель Modelica и графики расчёта

Исходник модели на [Modelica](https://modelica.org/) и графики её расчёта под ним. Считает не
страница, а MCP-инструмент `modelica_run`: OpenModelica 1.27.1 со стандартной библиотекой
Modelica 4.1 в песочнице. Он возвращает `artifact:<id>/result.csv` — эту строку и пишут в начале
блока вместе с тем, что рисовать:

```modelica
// result: artifact:a73c81b07a6561f0/result.csv
// plot: C.v
// plot: R.i
model RC "Заряд конденсатора через резистор"
  import Modelica.Electrical.Analog.Basic;
  import Modelica.Electrical.Analog.Sources;
  Sources.ConstantVoltage U(V = 10);
  Basic.Resistor R(R = 1000);
  Basic.Capacitor C(C = 1e-3, v(start = 0, fixed = true));
  Basic.Ground G;
equation
  connect(U.p, R.p);
  connect(R.n, C.p);
  connect(C.n, U.n);
  connect(U.n, G.p);
  annotation(experiment(StopTime = 5));
end RC;
```

- `// result:` — результат расчёта, только `artifact:<id>/result.csv` с этого сайта.
- `// plot: a, b` — переменные на одном графике (до восьми); каждая строка `plot` — свой график.
  Без `plot` — первые шесть переменных результата. По X — время.
- `// set: m_body = 350` — другое значение параметра модели, без правки самой модели; строк `set`
  может быть несколько. `modelica_run` принимает то же аргументом `set: {"m_body": 350}` и в ответе
  `block` пишет эти строки сам.

**Параметры полями ввода.** Под исходником — поля для всех `parameter Real|Integer|Boolean имя =
<число> "пояснение";` модели (выражения вроде `= 2 * m` не правятся полем). Читатель меняет
значения и нажимает «↻ пересчитать» (или Enter): модель считается с ними, графики — новые, а в
тексте блока — строки `// set:`. Пересчитать параметры уже посчитанной модели можно **без входа**:
шлюз сверяет, что текст модели тот же, что в её результате `// result:`, и меняет только значения.
Модель правили — пересчитывает только вошедший. Графики посчитаны с другими значениями, чем в
строках `set`, — блок скажет. Пояснение в кавычках после значения — подпись поля: пишите его.

- `// animate: …` — сцена над графиками: фигуры, привязанные к переменным. Координаты и размеры —
  числа или имена переменных результата, можно с минусом (`-h`); вычислений нет. Ось Y — вверх,
  масштаб по осям одинаковый, кадр — по всему расчёту.

| Фигура | Запись |
|---|---|
| отрезок | `line 0,0 x,y` |
| круг | `circle x=x y=y r=0.05` |
| прямоугольник | `rect x=mass.s y=0 w=0.06 h=0.04` (центр в x, y) |
| пружина | `spring -0.3,0 mass.s,0 n=10 w=0.05` (витков, ширина) |
| стрелка | `arrow 0,0 x,y` |
| точка | `point x=x y=y` |
| след | `trace x=x y=y` — путь до текущего момента |

У любой фигуры — `color=#c05621` и подпись после `|`: `circle x=0 y=h r=0.05 | мяч`.

Под графиками — шкала времени: «▶» проигрывает расчёт (в реальном времени, если он от 2 до
20 с, иначе целиком за 10 с), ползунок переводит на любой момент, курсор бежит по всем графикам,
рядом — значения переменных в этот момент.

**3D MultiBody.** У моделей на `Modelica.Mechanics.MultiBody` (в исходнике есть «MultiBody»
или `animation: true` у `modelica_run`) песочница отдаёт ещё `anim.json` — формы тел (брусы,
цилиндры, шары, конусы, пружины, трубы) и их положения во времени. Блок показывает их над
графиками на WebGL: тянуть — повернуть, колесо — приблизить, «⤢» — на весь экран; шкала
времени общая с графиками. Формы из файлов (`modelica://…stl`) пока не рисуются — блок скажет.

**Телефон и слои.** Атрибуты в строке забора: ` ```modelica view=scene ` — только 2D-анимация
(`3d`, `plots` — через запятую); `touch=views` и `gyro=on` — как у `stl`. На сенсорном экране
3D-модель в документе жесты не забирает (палец листает страницу; вертеть — кнопками видов, «⟳»,
наклоном или на весь экран), а графики под анимацией на узком экране свёрнуты — «Графики» их открывает.

Если в результате нет переменной, блок подскажет похожую и перечислит, что есть. Если исходник
правили после расчёта, блок скажет, что график — для другой версии. Без строки `result` блок —
просто исходник с пометкой «не рассчитана».

`modelica_run`: `model` — исходник целиком; `stopTime`, `intervals` (точек вывода, по умолчанию
500), `variables` — какие переменные сохранить (`"C.v"`, `"R.*"`). Библиотеки — только
стандартная Modelica; `external`-функции и файлы работают только внутри песочницы.

**Серия расчётов в сеансе** (где включены долгие сеансы, пресет `/mcp/p/modelica`):
`modelica_session_open {model, name?}` собирает модель один раз (секунды) на сборке
`openmodelica-1.27.1-session` и возвращает изменяемые параметры с единицами и значениями.
`modelica_simulate {session, set?, stopTime?, intervals?, variables?}` считает ту же программу с
другими значениями — десятые доли секунды, без перекомпиляции: `set` — `{"k": 2, "R1.R": 20}`, только
параметры из ответа открытия (структурные и вычисленные при сборке менять нельзя — для них новый сеанс).
Ответ — `final` (последние значения до 20 переменных), `result.csv` и строки блока; `// set:` в блоке —
только для параметров, объявленных в самой модели, остальные придут в `warning`. Неверный параметр —
ошибка без пересборки. Простой 15 минут — сохраняются модель и последние параметры, следующий расчёт
соберёт модель заново. MultiBody-анимации в сеансе нет — её даёт `modelica_run`.

Сборка ядра `openmodelica-1.27.1-session` имеет статус `next` (на пробу).
Пользовательского пакета save/from у Modelica нет: для возвращения после закрытия сохраните
исходный `.mo` и параметры, затем откройте расчёт заново. Внутреннее восстановление после
простоя не заменяет сохранение исходников. [Все ядра](https://github.com/kscht/spiridus-docs/blob/main/sessions.md).


## Ограничения статей проектов

На страницах проектов `/p` пересчёта у читателя пока нет, а готовый блок с `artifact:`
записать в статью нельзя. Картинку сохраняйте ресурсом проекта, модель — приложенным файлом.
Описанный выше пересчёт относится к прежним `/d` и живому редактору.
[Ограничения проектов](https://github.com/kscht/spiridus-docs/blob/main/projects.md#ресурсы-и-серверные-блоки).
