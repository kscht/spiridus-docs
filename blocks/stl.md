# `stl` — 3D-модель STL

Модель STL текстом (ASCII, `solid … facet … vertex … endsolid`) прямо в блоке — для простых
моделей, до 512 КБ. Или одна строка — ссылка на файл на этом сайте:

- `artifact:<id>/model.stl` — результат `cad_run` (FreeCAD в песочнице, MCP-шлюз);
- `/artifacts/<id>/model.stl` — то же адресом.

Чужие адреса не загружаются: это раскрыло бы читателя постороннему серверу.

```stl
artifact:08e4d5eeee8e3c5d/model.stl
```

В документе модель рисуется в SVG и вращается перетаскиванием; под ней — число треугольников,
габариты и объём. «⤢» — просмотр на WebGL: вращение, приближение, сдвиг, каркас, сетка с осями.
Под моделью из `cad_run` — кнопки скачать не только STL, но и исходники: **FCStd** (документ
FreeCAD; внутри и сценарий — текстовым объектом `script.py` рядом с моделью), **STEP** (для других
CAD) и **сценарий** (`script.py`, которым модель построена). Кнопки — для тех файлов, что есть в
результате: `cad_run` с `exports: ["stl"]` выгружает только STL; по умолчанию — все три.
Под моделью из `blender_run` — **.blend** (сцена целиком: модели, материалы, свет, камера) и
**сценарий**. `blender_run` выгружает `model.stl` сам, если сценарий STL не выгрузил, а меши в сцене
есть; `max_triangles` огрубляет сетку модификатором Decimate только на выгрузку — сцена та же.

Чтобы модель можно было править в FreeCAD, сценарий строит её параметрическими объектами —
`doc.addObject("Part::Box", …)`, `Part::Cut`, эскизы, PartDesign: в FCStd останется дерево с
размерами. `Part.makeBox(…)` и `obj.Shape = …` дают в файле замороженную форму без параметров.
Модель от таблицы параметров (Spreadsheet с именованными ячейками) `cad_run` отдаёт блоком
[`freecad`](freecad.md): под моделью — поля параметров, читатель пересчитывает её сам.

Советы сценарию `cad_run`:
- Булевы операции с B-сплайнами (лофт, протягивание) ломаются молча — тело выходит вывернутым
  (объём с минусом) или с дырами. Объединяйте и вычитайте с допуском: `a.fuse(b, 0.01)`,
  `a.cut(b, 0.01)`. `cad_run` предупредит в `warnings`: отрицательный объём, невалидная форма,
  незамкнутая сетка.
- Габариты в своих `print` — `s.optimalBoundingBox()`: `s.BoundBox` у B-сплайнов шире формы.
  `bbox` в ответе `cad_run` уже точный.
- Чтобы модель вращалась в документе, в ней не больше 60 000 треугольников: `max_triangles: 60000`
  — `cad_run` огрубит сетку сам и скажет, с какой точностью (`deflection`, а у моделей из многих
  тонких стержней — и угловая, `angularDeflection`: круглые сечения станут многоугольниками).
- `PartDesign::LinearPattern` копирует элемент криво, если у исходной детали в `Placement` есть
  поворот: копии разлетаются (особенность FreeCAD). Повёрнутое повторяйте `PolarPattern` или
  явными телами в цикле, а поворот задавайте в эскизе, не в `Placement`.
- Элемент PartDesign упал — тело в сценарии выглядит пустым. `cad_run` называет упавшие элементы с
  причиной (`failed`, «Fillet (PartDesign::Fillet): BRep_API: command not done») и при ошибке
  возвращает вывод `print` сценария. Больше 250 000
  треугольников песочница не строит вовсе: слишком мелкий `deflection` огрубляется до этого предела.
Больше 60 000 треугольников — только на весь экран. Файл — до 64 МБ, текстовый или двоичный STL.

## Сечения и вырез

Строки настроек в начале блока, до модели; модель — дальше текстом или строкой `file:`.

```stl
file: artifact:8d2da09aed8809c6/model.stl
section А-А: x = 0
section Б-Б: z = 3
cut: y < 0
hatch: metal 45°
```

- `section <имя>: <плоскость>` — сечение (ГОСТ 2.305): под моделью чертёж контура со
  штриховкой, на модели — след плоскости с буквой. Имя можно не писать: А, Б, В… по порядку
  (без Ё, З, Й, О, Х, Ъ, Ы, Ь). До восьми сечений.
- `cut: <плоскость>` — вырез: часть модели за плоскостью убрана, срез заштрихован; на весь
  экран кнопка «вырез» включает и выключает его. Один на модель, но может быть из двух плоскостей:
  `cut: x < 0 & y < 0` убирает четверть — часть, где верны оба условия (вырез четверти, как на
  чертеже); заглушка со штриховкой — на каждой из двух граней.
- `hatch:` — штриховка (ГОСТ 2.306): `metal` (параллельные линии) или `nonmetal`
  (перекрещивающиеся), угол — `45°`, `-45°`, `30°`; шаг в единицах модели — `2mm`. Без шага —
  около сороковой доли сечения. Штриховка общая для всех сечений блока, как велит ГОСТ.
- `file:` — модель ссылкой, если удобнее записать её среди настроек.

Плоскость сечения: `z = 15` (в единицах модели), `z = 50%` (доля габарита — удобно для чужого
STL), `point 0 0 10, normal 1 1 0` (точка и нормаль). Вырез — со знаком: `x > 20` убирает всё,
где x больше 20, `z < 50%` — нижнюю половину, `point …, normal …` — сторону, куда смотрит нормаль.

**Как задать положение плоскости — варианты:**

| Запись | Что значит |
|---|---|
| `z = 15` | число в единицах модели |
| `z = 50%` | доля габарита модели по этой оси |
| `z = thick / 2 + 1mm` | выражение от параметров модели — только в блоке [`freecad`](freecad.md): имена из его таблицы, `+ − * /`, скобки; модель пересчитали — плоскость встала по новым размерам |
| `z = 50% slider` | ползунок под моделью: читатель двигает плоскость сам, от края до края габарита |
| `z = 30 slider 10..90` | ползунок в своих пределах — в единицах модели |
| `y < 0 slider 20%..80%` | ползунок выреза в пределах долей габарита |
| `point 0 0 10, normal 1 1 0 slider` | ползунок двигает наклонную плоскость вдоль нормали |

`slider` можно писать и по-русски — `движок`. Ползунок — у каждой плоскости, где он записан: у
сечений чертёж под моделью перерисовывается на ходу, у выреза — сама модель и заглушка; у выреза
из двух плоскостей — свой ползунок у каждой (`cut: x < 0 slider & y < 0 slider`).

Сечение считается по самой сетке, откуда бы она ни пришла. Если плоскость мимо модели, блок
скажет, где модель по этой оси. У дырявой сетки незамкнутые части контура — пунктиром, без
штриховки. Русские имена настроек тоже понимаются: `сечение`, `вырез`, `штриховка`, `файл`.

В блоке `openscad` те же настройки — комментариями в начале: `// section А-А: z = 50%`.

## Телефон и сенсорный экран

В документе вертикальное движение пальцем — прокрутка страницы, поэтому модель вертится пальцем
только вбок. Поведение задаётся атрибутами в строке забора:

- ` ```stl touch=views ` — кнопки «изо», «спереди», «сверху», «сбоку»; на сенсорном экране палец
  остаётся странице (на компьютере тянуть можно по-прежнему);
- ` ```stl touch=turntable ` — на сенсорном экране модель сразу вращается на столе, касание — пауза;
- ` ```stl gyro=on ` — кнопка «наклоном»: модель поворачивается вслед за наклоном телефона (на iPhone
  браузер спросит разрешение; на компьютере кнопки нет).

Атрибуты можно сочетать: ` ```stl touch=views gyro=on `. То же — у блока `openscad`.
