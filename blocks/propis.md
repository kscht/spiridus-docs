# `propis` — пропись

Строки прописи, как в тетради 1 класса: рабочая строка между двумя основными линиями, над и под
ней вспомогательные, наклонные под 65°. Текст — рукописным шрифтом; высота строчных букв ровно
в рабочую строку. Сначала настройки (по желанию), потом строки текста; длинная строка
переносится по словам.

```propis
Аа Бб Вв
Мама мыла раму.
```

```propis
шрифт: печатный
обводка: да
пустые: 1
Кот. Дом. Сок.
```

- `шрифт: пропись` — наклонный рукописный (Bad Script, по умолчанию); `шрифт: печатный` —
  печатные буквы от руки (Neucha), для 1 класса.
- `обводка: да` — буквы бледные, по ним обводят.
- `пустые: N` — после каждой строки N пустых строк для упражнения (0–10); без текста — просто
  чистый лист из N строк.
- `наклонные: нет` — без наклонных линий.

Лист — по ширине колонки, но не шире тетрадного (640 точек): на телефоне строки переносятся по
словам, а буквы остаются того же размера. Слово длиннее строки телефона (около 12 букв прописью)
не переносится — такие слова пишите отдельной строкой или короче.

Английские имена тоже понимаются: `font: script | print`, `trace`, `blank`, `slant`.
Шрифты — под SIL Open Font License, из пакета `data/fonts` на этом сайте. Не больше 60 строк.
