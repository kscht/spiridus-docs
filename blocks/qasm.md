# `qasm` — квантовая схема на OpenQASM

Квантовая программа на [OpenQASM](https://openqasm.com/) 2.0 или 3.0 — язык Qiskit и большинства
квантовых облаков. Блок рисует схему и **моделирует** её прямо в браузере (вектор состояния, до 12
кубитов): вероятности исходов измерения и амплитуды всех состояний. Ползунок «шаг» проходит схему
по операциям — видно, как меняется состояние после каждого вентиля. Можно писать и ` ```openqasm `.

```qasm
OPENQASM 3.0;
include "stdgates.inc";
qubit[2] q;
bit[2] c;
h q[0];
cx q[0], q[1];
c = measure q;
```

## Что понимает

- **Регистры**: OpenQASM 2 — `qreg q[3]; creg c[3];`, OpenQASM 3 — `qubit[3] q; bit[3] c;`; можно
  несколько.
- **Вентили** (qelib1.inc, stdgates.inc): `id x y z h s sdg t tdg sx sxdg`, повороты `rx ry rz p`
  (`u1`, `phase`), `u2 u3 u`, двухкубитные `cx cy cz ch swap iswap crx cry crz cp cu3`,
  трёхкубитные `ccx cswap ccz`. Вентиль на весь регистр — `h q;` (по каждому кубиту).
- **Параметры** — выражения: `rz(pi/4)`, `ry(2*theta)`, `u3(pi/2, 0, -pi)`; есть `pi`, `+ − * / ^`,
  `sin cos sqrt exp ln`.
- **Свои вентили** — `gate имя(параметры) кубиты { … }`: подставляются при разборе.
- `measure q -> c;` (2.0), `c = measure q;` (3.0), `reset q[0];`, `barrier q;`.

Не поддерживаются ветвления по результату (`if`), циклы, подпрограммы и `ctrl @` из OpenQASM 3 —
ошибка с номером строки. Измерения — в конце схемы: вентиль после измерения того же кубита —
ошибка (вектор состояния здесь не годится).

## Что показывает

- **Схема**: управление — точка, цель CNOT — ⊕, обмен — ×, измерение — шкала с двойной линией в
  классический регистр, барьер — пунктир; углы — дробью π.
- **Вероятности**: если есть измерения — исходов по классическим битам (`c[1]c[0]`, старший
  слева), иначе — всех состояний (до 32 ненулевых).
- **Амплитуды**: состояние `|q₂q₁q₀⟩` (кубит 0 — правый, как в Qiskit), амплитуда, вероятность,
  фаза.
- Больше 12 кубитов — только схема (до 24 кубитов). Не больше 64 КБ исходника.

## Как чинить замечания `render_check`

- `too-wide` — схема длиннее колонки: на телефоне она прокручивается, на весь экран — кнопка «⤢»; разбейте на этапы (`barrier` не сокращает длину) или вынесите повторяющийся кусок в `gate`.
