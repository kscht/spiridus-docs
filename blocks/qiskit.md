# `qiskit` — квантовая схема: Qiskit и ZX-исчисление

Программа OpenQASM 2.0 или 3.0, которую разобрал и промоделировал MCP-инструмент `quantum_run`:
Qiskit 2.5 и PyZX в песочнице без сети. Он возвращает готовый блок — строки `// result`, `// build`,
`// view` и исходник; читатель видит выбранные картинки, а под ними — свёрнутый «показать исходник».

```qiskit
// result: artifact:ca7de9c1946963b1/circuit.svg
// build: qiskit-2.5.2
// view: circuit, histogram, bloch
OPENQASM 2.0;
include "qelib1.inc";
qreg q[3];
creg c[3];
h q[0];
cx q[0],q[1];
cx q[1],q[2];
measure q -> c;
```

## Виды (`// view:`)

| Вид | Что |
|---|---|
| `circuit` | схема Qiskit (как в учебниках и документации IBM) |
| `histogram` | вероятности исходов измерения (или всех состояний, если измерений нет) |
| `bloch` | сфера Блоха каждого кубита (до 8 кубитов; у запутанных — точка внутри сферы) |
| `zx` | схема как **ZX-диаграмма**: зелёные (Z) и красные (X) узлы-«пауки», жёлтые — Адамар |
| `zx-reduced` | та же диаграмма после упрощения `full_reduce` правилами ZX-исчисления |

По умолчанию — `circuit, histogram`. Под картинками — вероятности, а для `zx` — сколько вентилей и
T-вентилей было и стало после оптимизации и проверка, что схема та же.

## ZX-исчисление

ZX-исчисление — графический язык квантовых схем: вентили превращаются в узлы, и правила
перерисовки упрощают диаграмму, не меняя того, что схема делает. На нём строятся оптимизаторы
схем (меньше T-вентилей — дешевле на компьютере с исправлением ошибок). Гровер на двух кубитах:

```qiskit
// result: artifact:09b172fa98596738/circuit.svg
// build: qiskit-2.5.2
// view: circuit, zx, zx-reduced
OPENQASM 2.0;
include "qelib1.inc";
qreg q[2];
h q;
cz q[0],q[1];
h q;
x q;
cz q[0],q[1];
x q;
h q;
```

## `quantum_run`

- `source` — OpenQASM 2.0 (`include "qelib1.inc"`) или 3.0 (`include "stdgates.inc"`), до 24 кубитов;
- вектор состояния — до 16 кубитов, амплитуды в ответе — до 6, сферы Блоха — до 8;
- `zx: false`, `bloch: false` — не строить; измерение посреди схемы — вектор не считается.

Живое моделирование прямо в браузере, без песочницы и с проходом по шагам, — блок `qasm`.
