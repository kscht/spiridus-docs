# `openscad` — 3D-модель OpenSCAD

Исходник OpenSCAD собирается прямо в браузере (OpenSCAD в WebAssembly) и показывается как блок
`stl`: вращение, сводка, «⤢» — WebGL на весь экран, кнопка STL — скачать результат.

```openscad
difference() {
  cube(20, center = true);
  sphere(13, $fn = 64);
}
```

- Всё должно быть в блоке: `import`, `include` и `use` файлов не поддерживаются.
- Исходник — до 64 КБ, сборка — до 90 с; первая модель на странице ждёт загрузки сборщика (~11 МБ).
- Гладкость окружностей задаёт `$fn`; без него OpenSCAD рисует их многоугольниками.
- Ошибка показывается текстом OpenSCAD, с номером строки.
