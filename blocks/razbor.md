# `razbor` — разбор слова и предложения

Строка из частей `текст/тег` через пробел. Морфемы одного слова на рисунке сливаются в слово,
знаки встают над своими частями: `п` — приставка, `к` — корень, `с` — суффикс, `о` — окончание,
`0` — нулевое окончание.

Члены предложения — слова через пробел, подчёркивание под словом: `1` — подлежащее,
`2` — сказуемое, `~` — определение, `--` — дополнение, `-.` — обстоятельство. Несколько слов
под одним знаком — в кавычках: `"женского пола"/-.`.

```razbor
при/п готов/к и/с тельн/с ый/о
```
```razbor
Маленький/~ ёжик/1 быстро/-. бежал/2 по/-. тропинке/--
```

Часть речи над словом — после `@`: `ёжик/1@сущ.`, `по/@предл.` (без знака члена предложения — только
подпись). Пробел внутри подписи — неразрывный. Спорный член предложения — `?` после знака: `тропинке/-.?`
рисует «?» у черты: проверьте, дополнение это или обстоятельство.

```razbor
Маленький/~@прил. ёжик/1@сущ. быстро/-.@нар. бежал/2@гл. по/-.?@предл. тропинке/-.?@сущ.
```

Такую запись по разбору анализатора даёт блок `conllu`: вид «члены предложения» и кнопка «razbor».

Каждая строка блока рисуется отдельной строкой рисунка. Не больше 4 КБ.
