# `hdl` — Verilog, SystemVerilog, VHDL со схемой и ресурсами

Код на Verilog, SystemVerilog или VHDL — и под ним схема RTL (регистры, мультиплексоры,
сумматоры, вентили — как в коде), а для ПЛИС — занятость кристалла и предельная частота. Рисует
не страница, а MCP-инструмент `hdl_synth`: Yosys 0.52, nextpnr 0.7, GHDL 5, netlistsvg — в
песочнице без сети. Он возвращает готовый блок: первой строкой — ссылка на результат, комментарием
языка (`//` в Verilog, `--` в VHDL), дальше — исходник.

```hdl
// result: artifact:00c6233db8660c5b/schematic.svg
// build: hdl-debian13
module counter #(parameter W = 4) (
  input  wire clk, rst, en,
  output reg  [W-1:0] q
);
  always @(posedge clk)
    if (rst) q <= 0;
    else if (en) q <= q + 1'b1;
endmodule
```

Читатель видит код (строки `result` и `build` скрыты), схему с кнопкой «⤢» и таблицу: для
`target: "generic"` — ячейки по типам, для `ice40`, `ecp5`, `gowin` — LUT, триггеры, BRAM, DSP и
выводы кристалла с процентом занятости и Fmax по каждому такту. Предупреждения Yosys (защёлки,
несколько драйверов, обрывы) — под таблицей.

## `hdl_synth`

- `source` — исходник одним текстом (несколько модулей можно) или `files` — имя → текст
  (`top.v`, `fifo.sv`, `alu.vhd`; `` `include "defs.vh" `` — по имени);
- `top` — верхний модуль; без него берётся модуль с портами, который не вставлен в другой —
  тестбенч рядом не мешает;
- `target` — `generic` (по умолчанию), `ice40` (`device`: `up5k`, `hx1k`, `hx8k`…), `ecp5`
  (`25k`, `45k`, `85k`), `gowin` (`GW1NR-LV9QN88PC6/I5`); `freq` — желаемая частота, МГц;
- `flatten` — схема без иерархии (по умолчанию — да, если модулей несколько).

Ответ — сводка (ячейки, Fmax, предупреждения) и готовые блоки `hdl` и `digitaljs`. Ошибка —
с файлом и строкой, как у компилятора. VHDL синтезируется через `ghdl --synth` (VHDL-2008, `std:
"93"` — старый стандарт).

## Что учесть

- Схема — для понимания, не для больших проектов: больше 800 элементов она не рисуется (ресурсы
  считаются всё равно) — нарисуйте подмодуль через `top`.
- Правили код — вызовите `hdl_synth` снова и замените блок: в результате хранится хеш исходника,
  расхождение показывается под схемой.
- Живая схема с переключателями — блок `digitaljs` из того же ответа; осциллограммы — `hdl_sim` и
  блок `vcd`; просто показать код без схемы — обычный блок ` ```verilog ` или ` ```vhdl `.
- Ограничения песочницы: до 32 файлов, 2 МБ исходников, 5 минут; смешанные проекты Verilog + VHDL
  пока не поддерживаются.

## Как чинить замечания `render_check`

- `too-wide` — схема шире колонки: `flatten: false` (подмодули ящиками), `top` — подмодуль, или разбить модуль; на телефоне схема открывается крупно кнопкой «⤢».

## Статьи проектов

Вызовите `hdl_synth` или `hdl_sim` с `project` (editor и выше), затем передайте
готовый блок в статью через `project_write` op `put`. Шлюз материализует `private:`
этого проекта в новый каталог ресурсов и заменит ссылку относительным путём от статьи.
В `hdl` и `digitaljs` используется `// result: ../media/results/…/schematic.svg`
или `circuit.json`; в `vcd` — строка `../media/results/…/wave.vcd`, `file:` или `result:`.
Свой результат `artifact:` и адрес `/artifacts/…` также можно материализовать;
чужого id недостаточно. При импорте своего `/d` право даёт его исходный текст.

HDL и DigitalJS одного синтеза сохраняются одним набором; VCD — отдельным.
Открытие статьи и `render_check` используют сохранённые байты без вычислительной песочницы.
Проверенный шлюзом набор показывает «заверено шлюзом» с инструментом, сборкой и imageId.
Без подтверждённого исполнения сведения подписаны «по данным meta.json, не заверено»; обычный ресурс без набора —
«происхождение/соответствие не проверено». Расхождение исходника со схемой остаётся замечанием.
Текстовый VCD по-прежнему можно вставлять прямо в блок.

Отдельные файлы набора нельзя заменять, добавлять, переносить или скрывать.
Для нового результата сохраните новый блок; набор без ссылок из всех статей (включая `%%`)
убирается из `main` тем же коммитом, история сохраняется. Переносите весь каталог набора:
шлюз перепишет ссылки. `restore` статьи возвращает её набор совместно; удалённая владельцем
версия не восстанавливается. Не публикуйте закрытые результаты через `files_publish`.
