# `digitaljs` — живая логическая схема

Схема по коду Verilog, SystemVerilog или VHDL, которую можно «потрогать»: входы — переключатели
и поля для чисел, выходы — лампочки и значения, на проводах видно, где 0, где 1; под схемой —
осциллограммы сигналов. Рисует [DigitalJS](https://github.com/tilk/digitaljs) (BSD-2) во фрейме-песочнице, а
схему для него собирает MCP-инструмент `hdl_synth` (Yosys → yosys2digitaljs) — он возвращает
готовый блок:

```digitaljs
// result: artifact:1b97022159558f3a/circuit.json
// build: hdl-debian13
module mux2 (input wire a, b, s, output wire y);
  assign y = s ? b : a;
endmodule
```

Исходник в блоке — для сверки: правили его после синтеза — под схемой замечание, вызовите
`hdl_synth` снова. Читатель исходник не видит (кнопка «DigitalJS» копирует схему); код рядом —
блоком `hdl` (схема и ресурсы) или ` ```verilog `.

Шины-входы и выходы (`[3:0]` и шире) показывают число **в десятичной записи** (основание меняется
списком у поля). Чтобы видеть биты по отдельности, а число — только на выходе, входы делают
однобитными (`input wire a0, a1, a2, a3`), а биты собирают в шину перед выходом:
`assign y = {c3, s3, s2, s1, s0};`. Схема шире колонки ужимается до её ширины (не мельче 0,6),
остальное — прокруткой или кнопкой «⤢» на весь экран.

## Пуск, осциллограммы и такт

Схема открывается **на паузе**: время не идёт, лента не ползёт. Переключили вход — схема отрабатывает
это изменение до конца (лампочки, ступенька на ленте) и снова стоит. «▶» — свободный ход времени.
Входы — щелчком по квадрату на схеме или кнопками «имя: 0/1» под ней (на телефоне — только кнопками).

Осциллограммы по умолчанию свёрнуты — кнопка «осциллограммы ▸»; запись идёт и в свёрнутых.
Атрибуты в строке забора: ` ```digitaljs monitor=on ` — открыты сразу, `monitor=off` — без них
(только управление и входы), `run=on` — схема идёт сразу.

Обозначения элементов — американские (ANSI, как в DigitalJS); `notation=gost` — прямоугольник со знаком
функции внутри («&» — И, «1» — ИЛИ, «=1» — исключающее ИЛИ) и кружок инверсии на выходе, по
ГОСТ 2.743-91. В IEC 60617 ИЛИ обозначают «≥1». Какие обозначения в учебнике, по которому учатся читатели
документа, — сверяйте с учебником, а не с этой справкой.

Под схемой — монитор: именованные сигналы (порты и регистры, до 10, такт первым) пишутся по тактам,
пока схема работает; другие провода — лупой при наведении на провод, убрать — «✖». Кнопки: «⏸» /
«▶» — пауза и пуск, «шаг» — на паузе до следующего изменения сигналов, «мельче» / «крупнее» — масштаб, «⇥ сейчас»
— к последнему такту, если ленту утащили назад. У шины — основание (hex, dec, bin) в строке сигнала.

Вход `clk` (`clock`, `такт`) из Verilog — обычный вход: кнопка «такт ⎍» подаёт импульс (1, затем 0),
«авто» — два такта в секунду. Регистры до сброса — `x`: в тексте документа подскажите читателю
порядок (включить `en`, `rst` в 1, такт, `rst` в 0), как в примере:

```digitaljs
// result: artifact:265e45bc3632c011/circuit.json
// build: hdl-debian13
// Счётчик по модулю 10 с разрешением и переносом — разряд десятичного счётчика
module bcd_counter (
  input  wire       clk,
  input  wire       rst,   // синхронный сброс
  input  wire       en,
  output reg  [3:0] q,
  output wire       carry  // 1 в такте перехода 9 → 0
);
  assign carry = en && (q == 4'd9);
  always @(posedge clk)
    if (rst)        q <= 4'd0;
    else if (carry) q <= 4'd0;
    else if (en)    q <= q + 4'd1;
endmodule
```

## Что учесть

- Для обучения: вентили, мультиплексоры, сумматоры, счётчики, регистры, автоматы — десятки
  элементов. Большой проект превращается в нечитаемую паутину: показывайте подмодуль (`top`).
- Память (`reg [7:0] mem [0:15]`) показывается блоком памяти, автоматы — как есть.
- Начальное состояние входов — нули, регистров — `x`; в `render_check` схема — картинкой в этом состоянии,
  без осциллограмм (живое — сценарием `interact`).
- До 4 МБ `circuit.json`.
