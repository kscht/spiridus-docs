# `python` — код на Python с запуском

Обычный блок кода на Python — с подсветкой и кнопкой «▶ Запустить». Программа выполняется у
читателя, в браузере (Pyodide — CPython 3.14 в WebAssembly), в песочнице на отдельном домене
volkodlak.ru: без доступа к странице, данным и сети. Вывод `print()` — под кодом, ошибки — с
трассировкой.

```python
from itertools import product

# задание 8 ЕГЭ: сколько слов из 5 букв К, О, Т, где буква К встречается ровно 2 раза
print(sum(1 for w in product("КОТ", repeat=5) if w.count("К") == 2))
```

Если в программе есть `input()`, под кодом появляется поле ввода: по строке на каждый вызов.

```python
n = int(input())
print(sum(int(input()) for _ in range(n)))
```

- Стандартная библиотека Python есть целиком; numpy, matplotlib и другие пакеты — пока нет.
- Каждый запуск — с чистого листа: переменные прошлого запуска не видны.
- Предел — 15 секунд и 64 КБ вывода; дольше — остановка.
- Первый запуск на странице загружает Python (около 15 МБ, дальше — из кеша).
- `render_check` код не выполняет — только показывает блок.
