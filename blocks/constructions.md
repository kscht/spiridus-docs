# constructions — построения циркулем и линейкой

Нотация строит статичный SVG по строгой последовательности примитивов. Точки пересечения
вычисляет блок; автор задаёт только свободные точки. Один неизменяемый снимок содержит
граф зависимостей, координаты, кандидатов, диагностику и численные проверки.
Это этап 2 #393 по сравнению #410. Пошаговый показ, перетаскивание и видео — будущие возможности.
Нотация имеет статус `next`: доступна в профиле с включёнными следующими нотациями;
наличие этой справки не означает включение в production.

## Грамматика

Одна команда на строку. Пустые строки и строки с `#` в начале пропускаются; комментарий
после команды не разрешён. Имена чувствительны к регистру: 1–32 латинские **или** русские
буквы, цифры и `_`, первая — буква. Повторное объявление, смешение алфавитов внутри имени
и пара визуально похожих имён (например, латинская `A` и кириллическая `А`) — ошибки.
Все зависимости объявляют раньше использующего их шага; циклы запрещены.

```text
точка A = (1.5,-2.5)
точка B = (5.5,-2.5)
отрезок(A,B) -> s
прямая(A,B) -> l
луч(A,B) -> r
окружность(A,длина(A,B)) -> c
многоугольник(A,B,C,D) -> p
подпись A "Точка A"
```

В последней геометрической команде C и D должны быть построены заранее.
Десятичный разделитель — **точка**, запятая разделяет аргументы и координаты;
экспоненциальная запись и десятичная запятая не принимаются. Отрезок ограничен A и B,
прямая бесконечна в обе стороны, луч начинается в A и проходит через B. SVG обрезает
прямые и лучи по границам кадра; стрелка обозначает направление луча. Многоугольник
соединяет вершины в указанном порядке и замыкает последнюю сторону.
Радиус окружности задают только `длина(P,Q)` — циркуль с переносом раствора.
Готовых команд «перпендикуляр», «середина», макросов и произвольных вычислений в языке нет:
нужное построение записывают примитивами, как в примерах ниже.

Подписи задаются **в двойных кавычках**, до 80 символов; разрешены `\"` и `\\`.
Без команды подписи показано имя точки; `подпись A ""` скрывает подпись. Подписи относятся
только к точкам. Объекты не переопределяют; повторная подпись заменяет прежний текст.

## Пересечение и выбор кандидата

Объекты пересечения — ранее объявленные прямая, луч, отрезок или окружность.
Вложенная `прямая(A,B)` в `пересечение` не допускается: дайте прямой имя отдельной строкой.

```text
точка пересечение(a,b) выбрать слева(A,B) -> D
точка пересечение(b,d) выбрать кроме(A) -> C
точка пересечение(l,m) выбрать единственная() -> M
точки пересечение(a,b) -> U,V
```

Для одного имени селектор обязателен **всегда**, в том числе при касании.
Два имени разрешены только при двух разных кандидатах; порядок канонический: по возрастанию x, при разнице x в пределах линейного допуска —
по возрастанию y. Порядок не зависит от перестановки операндов; при повороте чертежа
он может измениться. Для устойчивого выбора геометрической стороны нужен селектор. Селекторы:

| Селектор | Условие |
|---|---|
| `слева(A,B)` / `справа(A,B)` | Строго слева/справа от ориентированного A→B в математических координатах (y вверх) |
| `та-же-сторона(A,B,P)` | Строго на той же стороне AB, что P |
| `другая-сторона(A,B,P)` | Строго на другой стороне AB относительно P |
| `кроме(P)` | Исключить кандидата, совпадающего с P в пределах допуска |
| `ближе(P)` | Ближайший к P; равные расстояния оставляют неоднозначность |
| `единственная()` | Множество уже содержит ровно одну точку |

После фильтра должен остаться **ровно один** кандидат. Граница стороны не считается
ни левой, ни правой. Нулевая ось селектора — ошибка. Новое имя точки ветвь не выбирает.
Касание даёт одну точку с признаком `tangent`, а не два дубля.

## Численные проверки

```text
проверить равны(длина(A,M),длина(M,B))
проверить равны(угол(U,O,S),угол(S,O,V))
проверить перпендикуляр(l,m)
проверить принадлежит(P,l)
проверить квадрат(A,B,C,D)
проверить правильный-многоугольник(p)
```

Угол — неориентированный в диапазоне [0,π]. Проверка квадрата проверяет ненулевые
стороны, различные вершины, выпуклый обход без пересечений, равные стороны и прямые
углы; правильного многоугольника — также равные внутренние углы. Отрезок/луч в проверке
принадлежности сохраняет свои границы. Любая невыполненная проверка делает блок ошибочным.
**Численная проверка одной конфигурации не доказывает теорему** и не проверяет решение
ученика на сервере. Допустимые операции ограничены самой грамматикой.

Вычисления — JavaScript double, локальная нормировка длин перед пересечением, линейный
допуск `1e-12 + 1e-12 × масштаб операции`; угловой допуск проверок `1e-10` радиан/косинуса.
Пересечения и отсечение по границам лучей/отрезков вычисляются в локальной системе
до возврата в мировые координаты. Снимок отдельно хранит `roundoff` — границу
ошибки представления мировых координат: `4 × Number.EPSILON × max(|x|,|y|)`
по входам и кандидатам. Проверка принадлежности учитывает её в дополнение к
линейному допуску. Превышение невязки или неразличимые в double ветви дают
`E_NUMERIC` для всего множества; численная ошибка не превращает два кандидата
в один. Настоящее отсечение по границам луча/отрезка сохраняется.
Координаты свободных и вычисленных точек и радиус — до 10⁹ по модулю; ненулевые длины
должны превышать линейный допуск. Почти параллельные направления с модулем синуса
до `1e-12` считаются параллельными. При близости к численным пределам измените масштаб
или исходные точки; это не символьная точная геометрия. Допуск не зависит от переноса
начала координат, но double ограничивает разрешение очень малых деталей при больших координатах.
Округление в SVG не используется для выбора кандидатов или проверки.

Пределы: 64 Ки символов, 3000 строк, 1000 узлов (пересечение и выбор — два узла),
глубина выражения 8, многоугольник до 64 вершин. Строка разбирается последовательным
сканером и разбором токенов с линейной сложностью по длине ввода; пробельные группы
не перебираются регулярными выражениями. Вычислитель не использует DOM, сеть,
секреты и сторонние библиотеки. Путь `page` выбран для собственного ограниченного парсера
и SVG по договору 0071; текст документа не исполняется как код.

## Диагностика

Ошибка содержит код, строку/колонку, узел, операцию, имена входов, причину и способ
исправления; ошибки выбора содержат кандидатов. Последующие шаги получают `E_BLOCKED`
и `blockedBy`, координаты вымышленной точки не подставляются. Снимок сохраняет результат
пересечения `two|one|none|coincident|parallel|invalid`, кандидатов, допуск и остатки.

| Код | Причина и исправление |
|---|---|
| `E_EMPTY` | Добавьте команды построения: в блоке только пробелы/комментарии |
| `E_SYNTAX`, `E_DECIMAL`, `E_NAME`, `E_LABEL` | Исправьте грамматику, десятичную точку, имя или кавычки/длину подписи |
| `E_DUPLICATE`, `E_CONFUSABLE` | Дайте объектам разные имена с однозначным алфавитом |
| `E_UNKNOWN`, `E_FORWARD`, `E_CYCLE` | Объявите зависимости раньше, устраните цикл |
| `E_TYPE` | Проверьте типы и число аргументов; радиус — `длина(P,Q)` |
| `E_ZERO_RADIUS`, `E_ZERO_SEGMENT`, `E_ZERO_ANGLE` | Задайте разные точки и ненулевой раствор/стороны |
| `E_PARALLEL` | Параллельные прямые не задают конечную точку |
| `E_COINCIDENT` | Совпадение окружностей/прямых или общий интервал лучей/отрезков: бесконечно много точек |
| `E_NO_INTERSECTION` | Нет пересечения с учётом границ объектов; измените исходные точки или раствор |
| `E_SELECTOR_REQUIRED`, `E_SELECTOR_EMPTY`, `E_SELECTOR_AMBIGUOUS`, `E_SELECTOR_AXIS` | Добавьте или исправьте геометрический селектор |
| `E_CARDINALITY` | Для пары имён нужны два разных кандидата |
| `E_ASSERTION` | Исправьте построение или порядок вершин |
| `E_RANGE`, `E_NUMERIC`, `E_LIMIT`, `E_POLYGON` | Уменьшите масштаб, число команд или вершин; устраните численное вырождение |

## Серединный перпендикуляр

```constructions
точка A = (40,40)
точка B = (80,40)
окружность(A,длина(A,B)) -> a
окружность(B,длина(A,B)) -> b
точки пересечение(a,b) -> U,V
прямая(U,V) -> m
прямая(A,B) -> base
точка пересечение(m,base) выбрать единственная() -> M
отрезок(A,B) -> answer
подпись M "Середина"
проверить перпендикуляр(m,base)
проверить равны(длина(A,M),длина(M,B))
```

## Квадрат по стороне без координат производных точек

```constructions
точка A = (40,40)
точка B = (80,40)
прямая(A,B) -> base
окружность(A,длина(A,B)) -> a
точка пересечение(a,base) выбрать кроме(B) -> E
окружность(B,длина(B,E)) -> b0
окружность(E,длина(B,E)) -> e0
точки пересечение(b0,e0) -> F,G
прямая(F,G) -> n
точка пересечение(a,n) выбрать слева(A,B) -> D
окружность(B,длина(A,B)) -> b
окружность(D,длина(A,B)) -> d
точка пересечение(b,d) выбрать кроме(A) -> C
многоугольник(A,B,C,D) -> answer
проверить квадрат(A,B,C,D)
```

Точка E получается продолжением AB; окружности с центрами B,E строят перпендикуляр
в A. Селектор C исключает уже существующую A. Многоугольник включает сторону DA.
Ещё четыре эталона — перпендикуляр из внешней точки, биссектриса, перенос угла и
правильный шестиугольник — в приёмочном документе нотации `examples/basic.md`.
Для обычных геометрических иллюстраций без вычислимого графа построений подходит `tikz`.
