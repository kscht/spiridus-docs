# `smiles` — структурные формулы и схемы реакций

Запись SMILES одной строкой. Одна молекула — скелетная формула; запись с `>`/`>>` — схема
реакции: реагенты, над стрелкой — условия и катализаторы, справа — продукты.

```smiles
CC(=O)Oc1ccccc1C(=O)O
```
```smiles
CC(=O)O.CCO>[H+]>CC(=O)OCC.O
```

Не больше 500 символов. Неразобранная запись остаётся исходником с отметкой.

Ловушки:
- Над стрелкой реакции — тоже SMILES: `>OS(=O)(=O)O>`, а не `>[H2SO4]>` (такая запись не
  разбирается, и вся схема остаётся исходником).
- Несколько молекул через точку рисуются россыпью — ряд молекул пишите по строке (ниже).

**Ряд молекул** — по молекуле на строку, после ` | ` — подпись под молекулой (изомеры, гомологи, ряд
соединений). Масштаб у всех один, на узком экране ряд переносится.

```smiles
CCCCO | бутанол-1
CC(O)CC | бутанол-2
CC(C)CO | 2-метилпропанол-1
CC(C)(C)O | 2-метилпропанол-2
```

**Подсветка части молекулы** — строка `highlight:` (или `подсветить:`): названия групп или шаблоны SMARTS через
запятую, у каждой свой цвет, под рисунком — легенда. Группы: гидроксил, карбоксил, карбонил, альдегид,
кетон, сложный эфир, простой эфир, аминогруппа, амидная группа, пептидная связь, нитрогруппа, нитрил, тиол,
сульфогруппа, фосфатная группа, галоген, бензольное кольцо, двойная связь, тройная связь (и привычные
синонимы: OH, COOH, NH2, гидроксогруппа…). Не нашлось — предупреждение под рисунком. У схем реакций
подсветки нет.

```smiles
CC(=O)Oc1ccccc1C(=O)O | аспирин
NCC(=O)NCC(=O)O | глицилглицин
highlight: карбоксил, сложный эфир, пептидная связь
```
