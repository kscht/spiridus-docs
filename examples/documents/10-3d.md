# 3D-модели: STL и OpenSCAD

Модель вращается перетаскиванием (на телефоне — жестом вбок), двойное нажатие — исходный вид. Кнопка «⤢» открывает просмотр на WebGL: вращение, приближение колесом или щипком, сдвиг, каркас, сетка с осями.

Простая модель текстом прямо в документе — пирамида в ASCII STL:

```stl
solid pyramid
  facet normal 0.000 0.000 -1.000
    outer loop
      vertex 0 0 0
      vertex 20 20 0
      vertex 20 0 0
    endloop
  endfacet
  facet normal 0.000 0.000 -1.000
    outer loop
      vertex 0 0 0
      vertex 0 20 0
      vertex 20 20 0
    endloop
  endfacet
  facet normal 0.000 -0.874 0.486
    outer loop
      vertex 0 0 0
      vertex 20 0 0
      vertex 10 10 18
    endloop
  endfacet
  facet normal 0.874 0.000 0.486
    outer loop
      vertex 20 0 0
      vertex 20 20 0
      vertex 10 10 18
    endloop
  endfacet
  facet normal 0.000 0.874 0.486
    outer loop
      vertex 20 20 0
      vertex 0 20 0
      vertex 10 10 18
    endloop
  endfacet
  facet normal -0.874 0.000 0.486
    outer loop
      vertex 0 20 0
      vertex 0 0 0
      vertex 10 10 18
    endloop
  endfacet
endsolid pyramid
```

OpenSCAD — исходник собирается в браузере:

```openscad
difference() {
  cube(20, center = true);
  sphere(13, $fn = 64);
}
```

```openscad
// шестерня: зубья — поворотом одного профиля
teeth = 18; r = 20; h = 6;
difference() {
  union() {
    cylinder(r = r, h = h, $fn = 90);
    for (i = [0 : teeth - 1]) rotate([0, 0, i * 360 / teeth])
      translate([r - 1, -1.6, 0]) cube([4, 3.2, h]);
  }
  translate([0, 0, -1]) cylinder(r = 5, h = h + 2, $fn = 48);
}
```
