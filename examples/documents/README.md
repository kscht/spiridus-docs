# Документы-примеры

Готовые документы Spiridus — те же, что на стенде https://v2.spiridus.ru/render/. Каждый проходит проверку
`render_check`; блоки, которые рисует сервер, ссылаются на готовые результаты (`result: artifact:…`).
Берите за образец синтаксис и приёмы. Лицензия — MIT-0, как у всей папки [examples](../).
