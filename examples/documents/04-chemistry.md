# Химия: формулы и молекулы

Уравнения mhchem прямо в тексте: $\ce{CH4 + 2O2 -> CO2 + 2H2O}$, $\ce{Fe^{3+} + 3OH- -> Fe(OH)3 v}$, количество $\pu{1.5 mol/L}$.

Структурная формула по SMILES — аспирин:

```smiles
CC(=O)Oc1ccccc1C(=O)O
```

Этерификация: $\ce{CH3COOH + C2H5OH <=>[H+] CH3COOC2H5 + H2O}$. Структурные формулы реагентов и продуктов — отдельными рядами, которые переносятся на телефоне.

Исполняемый синтаксис реакции `реагенты>катализатор>продукты` — компактный перенос протона от воды к аммиаку: $\ce{NH3 + H2O <=> NH4+ + OH-}$. Между двумя `>` здесь нет катализатора.

```smiles
N.O>>[NH4+].[OH-]
```

Вариант с непустым полем катализатора — кислотно-катализируемая гидратация этена до этанола; протон записан SMILES над стрелкой:

```smiles
C=C.O>[H+]>CCO
```

Реагенты:

```smiles
CC(=O)O | уксусная кислота
CCO | этанол
```

Продукты:

```smiles
CC(=O)OCC | этилацетат
O | вода
```

Молекула в 3D — потяните, чтобы повернуть; двойное нажатие возвращает вид:

```mol3d
CCO
```

```mol3d
OC[C@H]1OC(O)[C@H](O)[C@@H](O)[C@@H]1O
```
