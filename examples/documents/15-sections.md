# Сечения и вырезы

Сечение считается по сетке треугольников в браузере. Модель может быть любой: чужой STL, OpenSCAD, FreeCAD. Плоскость и штриховка задаются строками над моделью.

## Фланец: два сечения и вырез половины

Сечение А–А идёт вдоль оси через ступицу, Б–Б — поперёк, через диск с отверстиями. Вырез убирает переднюю половину, срез заштрихован. Нажмите «⤢», а там — «вырез», чтобы увидеть фланец целиком.

```stl
file: artifact:8d2da09aed8809c6/model.stl
section А-А: x = 0
section Б-Б: z = 3
cut: y < 0
```

## Кронштейн: сечение через отверстия

Плоскость проходит через оси отверстий: видно, как они режут полку и стенку, и скругление внутреннего угла.

```stl
file: artifact:7fca8326ca566d68/model.stl
section: x = 10
section: x = 20
hatch: metal 45° 1mm
```

## OpenSCAD: ваза, толщина стенки

Настройки — комментариями в начале исходника, чтобы он оставался обычным OpenSCAD.

```openscad
// cut: x > 0
// section А-А: z = 25%
// section Б-Б: point 0 0 0, normal 1 0 0
rotate_extrude($fn = 96)
  polygon([[0, 0], [14, 0], [18, 10], [12, 28], [10, 36], [13, 42],
           [11.5, 42], [8.5, 36], [10.5, 28], [16.5, 10], [12.5, 1.5], [0, 1.5]]);
```

## Неметалл и наклонная плоскость

```openscad
// section: point 0 0 6, normal 1 0 1
// hatch: nonmetal
difference() {
  cube([30, 20, 12], center = true);
  cylinder(r = 5, h = 20, center = true, $fn = 48);
}
```
