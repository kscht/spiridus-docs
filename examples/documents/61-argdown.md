# Карты аргументации

Переключайте «Карта», «Аргументы», «Оба вида». Выберите узел карты, чтобы прочитать полный текст довода и выделить его связи.

```argdown view=both
[Велодорожка]: На улице нужна отделённая велодорожка.
  + <Безопасность>: Разделение потоков снижает риск столкновений.
  - <Расходы>: Строительство требует денег.
    - <Совмещение>: Работы можно совместить с ремонтом улицы.

<Безопасность>

(1) На улице происходят столкновения автомобилей с велосипедистами.
(2) Разделение потоков уменьшает риск столкновений.
----
(3) [Велодорожка]
```
