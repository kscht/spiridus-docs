# Разбор слова и предложения

Части слова — слитно, через «текст/тег»: п — приставка, к — корень, с — суффикс, о — окончание, 0 — нулевое окончание.

```razbor
при/п готов/к и/с тельн/с ый/о
```

```razbor
под/п снеж/к ник/с 0/0
```

Члены предложения — через пробел: 1 — подлежащее, 2 — сказуемое, ~ — определение, -- — дополнение, -. — обстоятельство.

```razbor
Маленький/~ ёжик/1 быстро/-. бежал/2 по/-. тропинке/--
```
