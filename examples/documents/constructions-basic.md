# Построения циркулем и линейкой

Шесть эталонов этапа 2 #393. Все производные точки вычисляет блок.

## Серединный перпендикуляр

```constructions
точка A = (40,40)
точка B = (80,40)
окружность(A,длина(A,B)) -> a
окружность(B,длина(A,B)) -> b
точки пересечение(a,b) -> U,V
прямая(U,V) -> m
прямая(A,B) -> base
точка пересечение(m,base) выбрать единственная() -> M
отрезок(A,B) -> answer
подпись M "Середина"
проверить перпендикуляр(m,base)
проверить равны(длина(A,M),длина(M,B))
```

## Перпендикуляр из внешней точки

```constructions
точка A = (40,40)
точка B = (80,40)
точка P = (60,70)
прямая(A,B) -> base
окружность(P,длина(P,A)) -> p
точки пересечение(p,base) -> X,Y
окружность(X,длина(X,Y)) -> a
окружность(Y,длина(X,Y)) -> b
точки пересечение(a,b) -> U,V
прямая(U,V) -> m
точка пересечение(m,base) выбрать единственная() -> H
отрезок(P,H) -> answer
проверить принадлежит(P,m)
проверить перпендикуляр(m,base)
```

## Квадрат по стороне

```constructions
точка A = (40,40)
точка B = (80,40)
прямая(A,B) -> base
окружность(A,длина(A,B)) -> a
точка пересечение(a,base) выбрать кроме(B) -> E
окружность(B,длина(B,E)) -> b0
окружность(E,длина(B,E)) -> e0
точки пересечение(b0,e0) -> F,G
прямая(F,G) -> n
точка пересечение(a,n) выбрать слева(A,B) -> D
окружность(B,длина(A,B)) -> b
окружность(D,длина(A,B)) -> d
точка пересечение(b,d) выбрать кроме(A) -> C
многоугольник(A,B,C,D) -> answer
проверить квадрат(A,B,C,D)
```
