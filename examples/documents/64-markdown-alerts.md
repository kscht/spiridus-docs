# Плашки Markdown

Плашка — обычная цитата с отметкой вида в первой строке. Она выделяет важный текст,
сохраняя переносимость Markdown.

> [!NOTE]
> Дополнительные сведения: документ можно читать и без них.

> [!TIP]
> Совет: оставляйте пустую строку между плашками, чтобы они не сливались в одну цитату.
>
> - Внутри работает **выделение**.
> - Можно добавлять [[#Обычные цитаты|ссылки на разделы]].

> [!IMPORTANT]
> Важно: сохраните исходный файл перед обработкой.
>
> ```text
> исходник.md → копия.md
> ```

> [!WARNING]
> Внимание: обработка большого файла может занять несколько минут.

> [!CAUTION]
> Осторожно: удаление файла нельзя отменить без резервной копии.

## Обычные цитаты

Неизвестный вид и отметка ниже первой строки сохраняются как обычные цитаты:

> [!FOO]
> Эта отметка не поддерживается.

> Обычная первая строка.
> [!NOTE]
> Отметка здесь — часть текста.

Запись плашки в исходнике:

```md
> [!NOTE]
> Текст примечания.
```
