# Данные и их использование

Spiridus — исследовательский проект. Всё, что вы отправляете через API и MCP, **сохраняется и
используется, чтобы улучшать проверки Spiridus**: линтеры блоков, `render_check`, проверку текста и
правила починки — находить, где они ошибаются, пропускают ошибку или ругаются зря.

Что сохраняется:

- документы и исходники блоков (диаграммы, схемы, код, модели);
- запросы к инструментам и их результаты: рисунки, замечания проверки, разборы;
- описание задачи, которое модель передаёт вместе с вызовом (поле `task`: что попросил пользователь,
  своими словами модели) — сама переписка с моделью остаётся у вас, в вашем клиенте;
- история правок общих документов и ссылок, которыми вы делитесь.

Не присылайте того, чем не готовы поделиться: чужого кода и текстов без права на это, персональных
данных других людей, секретов.

**Адрес почты** нужен только для доступа: на него приходит ключ API. Для улучшения проверок он не
используется. IP-адреса не хранятся.

## Кто видит

- **Результаты инструментов** (рисунки, модели, файлы — ссылки `https://v2.spiridus.ru/artifacts/…`)
  открываются по ссылке без ключа: так их показывает документ у любого читателя. Ссылка случайная и
  длинная, перебором её не найти, но кому вы её дали — тот увидит.
- **Опубликованные документы** (`document_share`, ссылки `https://v2.spiridus.ru/d/…`) — по ссылке
  без ключа, со всеми прежними версиями, у любого, кому её передали. Ссылка случайная, в поисковики
  страница не отдаётся. Менять и удалять документ можете только вы.
- **Опубликованные картинки** (`files_publish`) становятся результатами: видны по ссылке без ключа,
  как рисунки инструментов, и хранятся по их правилам. Удаление учётной записи их не удаляет — если
  нужно убрать опубликованное, напишите на [kscht@tutamail.com](mailto:kscht@tutamail.com).
- **Свои файлы** (`upload:<id>/<имя>`) — только с ключом. Ссылку можно передать другому участнику:
  со своим ключом он сможет пользоваться файлом и скачать его — **на ваш страх и риск**. Удалите файл —
  ссылка перестанет работать у всех. id получается из содержимого: кто знает содержимое файла, может
  проверить, загружали ли его, — не загружайте так секретное.

## Сколько хранится

Сейчас **альфа-тестирование**:

- файлы, результаты и кеш **гарантированно хранятся сутки**; позже удаляются, только если на сервере
  кончается место — сначала самое старое. Не рассчитывайте, что ссылка из документа будет работать
  всегда: нет результата — перерисуйте блок;
- **опубликованный документ живёт, пока жива учётная запись**: его и результаты, на которые он
  ссылается, уборка не трогает. Удаляется учётная запись — удаляется и документ со всей историей версий,
  ссылка перестаёт открываться;
- **учётная запись без обращений больше недели удаляется сама** — вместе с ключом, файлами, сайтами и опубликованными документами;
  удалять её вручную не нужно. Захотите вернуться — зарегистрируйтесь снова;
- журнал вызовов хранится для улучшения проверок; после удаления учётной записи записи в нём остаются
  без почты, под обезличенным номером.

**Удалить учётную запись раньше** — `DELETE /api/v1/me` с ключом (или инструмент `account_delete` в MCP):
удаляются запись, ключ, файлы, сайты и опубликованные документы, ключ перестаёт работать сразу. Ключа нет — напишите на
[kscht@tutamail.com](mailto:kscht@tutamail.com) с адреса, на который зарегистрирована запись.
